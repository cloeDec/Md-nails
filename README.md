# MD-Nails — site vitrine (HTML / CSS / JS)

Fichiers :
- index.html   structure de la page
- styles.css   styles (noir, blanc, doré)
- script.js    liens réseaux/réservation, scroll doux, apparitions
- images/      vos photos

## À remplir
1. images/ : hero.jpg, portrait.jpg, g1.jpg … g8.jpg (format paysage pour g1/g4, portrait pour g2/g3, carré pour g5-g8).
2. index.html : adresse, téléphone, email, "[X] ans" d'expérience, avis clientes, @instagram.
3. script.js : objet LIENS (instagram, facebook, booking).

Couleur dorée : variable --gold en haut de styles.css.
Mise en ligne : déposez le dossier tel quel chez votre hébergeur (ou Netlify / GitHub Pages).
